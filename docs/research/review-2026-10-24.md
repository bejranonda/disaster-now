**The rule this host bends, and the owner's answer.** D-040 says "one server per app". This host runs another app's
production. Asked, the owner chose to run the collector here. The rule's reasons were FloodWatch-specific: a shared IP
for the same sources (ThaiWater's 429, KI-029), a copied `.env`, and FloodWatch's tunnel token. BrainPlatform calls none
of this app's sources, shares no `.env` and no tunnel; the stack binds 127.0.0.1:8090 only, runs read-only as a
non-root user, and touches no `deploy-*` container. D-040 is amended accordingly (D-045, [HISTORY](HISTORY.md)).

## The name (A2, decided)

The owner asked whether "Thai Risk" should be the name. The answer given, and taken:

- **"Thai Risk" alone** is short and matches `risk.autobahn.bot`, but in English it reads like a country or investment
  risk rating; beside "ThaiWater" (HII's official brand) it can look like a government service; and the audience
  reads Thai first, inside LINE.
- **"Disaster Now"** said "disaster" on a calm day.
- **Chosen: ภัยรอบบ้าน · Thai Risk.** The Thai name people will say, shortened so it fits the 320 px header on one line
  (0.3.0's "ภัยรอบบ้าน ตอน/นี้" wrapped, KI-027); "Thai Risk" as the English name; the footer now says "โครงการทดลองอิสระ
  ไม่ใช่เว็บของหน่วยงานรัฐ" / "an independent experiment, not a government site". The repository, the Worker, the
  KV namespace and the Docker project keep the code name `disaster-now`.
